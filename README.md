# Utilivo Calculator Reference Examples

Six reproducible business math examples designed for developers, educators and QA writers.

These are independent mathematical reference cases, not full production user-interface tests. They reflect selected Utilivo calculator formulas.

Try the tools: https://utilivo.tech/tools/calculators

Reference JSON: https://utilivo.tech/data/calculator-test-vectors.json

Run `node verify.mjs` with Node.js 18+; no dependencies or API keys are needed.

For a step-by-step explanation of each formula, boundary conditions, and a review checklist, see [Six calculator checks you can reproduce](docs/calculator-quality-checks.md).
